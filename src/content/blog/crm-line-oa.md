## LINE OA คืออะไร

LINE Official Account (LINE OA) คือบัญชี LINE สำหรับธุรกิจ ที่ให้ลูกค้าเพิ่มเป็นเพื่อนและทักแชทได้ ในประเทศไทย LINE มีผู้ใช้มากกว่า 50 ล้านคน ทำให้ LINE OA เป็นช่องทางสื่อสารกับลูกค้าที่สำคัญที่สุดสำหรับธุรกิจไทย

ฟังก์ชันของ LINE OA:
- แชทกับลูกค้า
- ส่งข้อความ Broadcast
- สร้าง Rich Menu
- ตั้งคีย์เวิร์ดอัตโนมัติ
- สร้าง LINE Form
- ดูสถิติผู้ติดตาม

อ่านพื้นฐาน CRM ได้ที่ [CRM คืออะไร? คู่มือฉบับสมบูรณ์](/blog/crm-guide/)

## ทำไมต้องเชื่อม CRM กับ LINE OA

### LINE คือช่องทางหลักของลูกค้าไทย

ธุรกิจไทยส่วนใหญ่ใช้ LINE เป็นช่องทางสื่อสารกับลูกค้า ลูกค้าทักถามสินค้า สั่งซื้อ แจ้งปัญหา ผ่าน LINE แต่ถ้า LINE แยกจาก CRM ข้อมูลลูกค้าก็กระจัดกระจาย

### ลูกค้าใน LINE ไม่ได้เข้า CRM

ถ้าลูกค้าทัก LINE แต่พนักงานไม่กรอกข้อมูลเข้า CRM ลูกค้าคนนั้นจะไม่อยู่ในระบบ ไม่มีประวัติ ไม่มีการติดตาม

### พนักงานหลายคนใช้ LINE ร่วมกัน

ถ้าพนักงาน 5 คนใช้ LINE OA ร่วมกัน ไม่รู้ว่าใครตอบลูกค้าคนไหน ไม่รู้ว่าลูกค้าคุยอะไรไปแล้ว

---

## ปัญหาของการใช้ LINE แยกจาก CRM

### ข้อมูลลูกค้าไม่เข้าระบบ

ลูกค้าทัก LINE แต่ไม่มีใครกรอกเข้า CRM ทำให้:
- ไม่รู้ว่าลูกค้าคนนี้เคยซื้ออะไร
- ไม่รู้ว่าเคยคุยอะไรไป
- ไม่มีประวัติในระบบ

### ตอบลูกค้าช้า

- ไม่รู้ว่าลูกค้าทักมา จนกว่าจะเปิด LINE
- หลายคนใช้ LINE ร่วมกัน ไม่รู้ว่าใครตอบ
- ไม่มีระบบแจ้งเตือน

### ไม่สามารถติดตามได้

- ลูกค้าทักมา ตอบแล้ว จบ
- ไม่มีระบบติดตาม
- ลูกค้าหายไป ไม่มีใครรู้

### ไม่มีรายงาน

- ไม่รู้ว่าเดือนนี้รับลูกค้าจาก LINE กี่คน
- ไม่รู้ว่าลูกค้าจาก LINE ปิดการขายกี่ดีล
- ไม่รู้ว่า LINE มีประสิทธิภาพแค่ไหน

## ประโยชน์ของการเชื่อม CRM กับ LINE OA

### ข้อมูลลูกค้าเข้า CRM อัตโนมัติ

เมื่อลูกค้าทัก LINE ข้อมูลเข้า CRM อัตโนมัติ ไม่ต้องกรอกเอง

### ประวัติการคุยเก็บใน CRM

ทุกข้อความที่คุยกับลูกค้าใน LINE เก็บใน CRM พนักงานคนอื่นเห็นได้ ลาออกก็ไม่หาย

### ตอบเร็ว

ระบบแจ้งเตือนเมื่อมีลูกค้าทัก พนักงานตอบได้เร็ว ไม่ต้องเปิด LINE ตลอด

### ติดตามได้

หลังคุยใน LINE สร้าง Task ติดตามใน CRM ได้ ไม่ลืม

### ส่งข้อความจาก CRM

ส่งข้อความ LINE ให้ลูกค้าจากใน CRM ได้ ไม่ต้องสลับระบบ

### รายงานรวม

รู้ว่า LINE ส่ง Lead กี่คน ปิดการขายกี่ดีล ROI เท่าไร

## วิธีเชื่อม CRM กับ LINE OA

### ขั้นตอนที่ 1: สมัคร LINE OA

ถ้ายังไม่มี LINE OA สมัครได้ที่ LINE Official Account Manager ฟรีสำหรับเริ่มต้น

### ขั้นตอนที่ 2: ขอ LINE Messaging API

1. เข้า LINE Developers Console
2. สร้าง Provider
3. สร้าง Channel (Messaging API)
4. รับ Channel Access Token และ Channel Secret

### ขั้นตอนที่ 3: เชื่อมใน CRM

ใน CBoom CRM:
1. ไปที่ Settings > Integrations
2. เลือก LINE OA
3. กรอก Channel Access Token และ Channel Secret
4. กดเชื่อมต่อ

### ขั้นตอนที่ 4: ตั้งค่า

- เลือกว่าจะให้ข้อความเข้า CRM อัตโนมัติ
- ตั้งค่าการแจ้งเตือน
- ตั้งค่าการสร้าง Lead อัตโนมัติ

### ขั้นตอนที่ 5: ทดสอบ

ทัก LINE OA ของคุณเอง ดูว่าข้อมูลเข้า CRM ไหม ข้อความเก็บไหม แจ้งเตือนไหม

## ฟังก์ชันที่ได้จากการเชื่อม

### 1. Auto Lead Creation

เมื่อลูกค้าทัก LINE ครั้งแรก ระบบสร้าง Lead ใน CRM อัตโนมัติ

### 2. Chat History

ทุกข้อความที่คุยใน LINE เก็บใน CRM พนักงานเห็นประวัติได้

### 3. Contact Sync

ข้อมูลลูกค้าจาก LINE (ชื่อ รูป) เข้า CRM อัตโนมัติ

### 4. Send Message from CRM

ส่งข้อความ LINE ให้ลูกค้าจากใน CRM ได้

### 5. Auto Reply

ตั้งค่าตอบอัตโนมัติเมื่อลูกค้าทักนอกเวลาทำการ

### 6. Broadcast from CRM

ส่งข้อความ Broadcast ถึงลูกค้า LINE จากใน CRM ได้

### 7. Notification

แจ้งเตือนพนักงานเมื่อมีลูกค้าทัก LINE ใหม่

### 8. Lead Routing

ส่งข้อความ LINE ให้พนักงานที่เหมาะสมอัตโนมัติ

## ตัวอย่างการใช้งานจริง

### สถานการณ์: ร้านค้าออนไลน์

1. ลูกค้าเห็นโฆษณา Facebook กด LINE เพื่อถามสินค้า
2. ลูกค้าทัก LINE OA ระบบสร้าง Lead ใน CRM อัตโนมัติ
3. พนักงานได้รับแจ้งเตือน เปิด CRM ดูข้อมูลลูกค้า
4. พนักงานตอบจากใน CRM ข้อความส่งไป LINE ลูกค้า
5. หลังคุย พนักงานสร้าง Task ติดตามใน CRM
6. วันถัดไป ระบบเตือนให้ติดตาม พนักงานส่งข้อความ LINE จาก CRM
7. ลูกค้าสั่งซื้อ พนักงานอัปเดตสถานะเป็น Won ใน CRM
8. ระบบส่งข้อความขอบคุณทาง LINE อัตโนมัติ

## ตัวอย่างจริงจากธุรกิจไทย

### กรณีที่ 1: ร้านเสื้อผ้า

**ก่อนเชื่อม:**
- ลูกค้าทัก LINE ถามสินค้า พนักงานตอบ แล้วลืม
- ไม่มีประวัติลูกค้าในระบบ
- ไม่รู้ว่าเดือนนี้รับลูกค้าจาก LINE กี่คน

**หลังเชื่อม:**
- ลูกค้าทัก LINE เข้า CRM อัตโนมัติ
- ประวัติการคุยเก็บใน CRM
- ติดตามลูกค้าได้ ปิดการขายเพิ่ม 30%
- รู้ว่า LINE ส่ง Lead 200 คน/เดือน ปิด 40 ดีล

### กรณีที่ 2: บริษัทขายบริการ

**ก่อนเชื่อม:**
- ลูกค้าทัก LINE นอกเวลา ไม่มีคนตอบ
- ลูกค้ารอ 1 วัน ไปหาคู่แข่ง

**หลังเชื่อม:**
- ระบบตอบอัตโนมัตินอกเวลา "ขอบคุณที่ทัก เราจะตอบในวันทำการ"
- สร้าง Lead ใน CRM อัตโนมัติ
- วันถัดไป พนักงานตอบและติดตาม
- ลูกค้าไม่หาย อัตราปิดเพิ่ม 20%

## FAQ

### เชื่อม CRM กับ LINE OA ทำไม

เพื่อให้ข้อมูลลูกค้าจาก LINE เข้า CRM อัตโนมัติ ประวัติการคุยเก็บในระบบ ตอบลูกค้าได้เร็ว ติดตามได้ และมีรายงานรวม

### เชื่อม CRM กับ LINE OA ยากไหม

ไม่ยาก ถ้าใช้ CBoom CRM เพียงกรอก Channel Access Token และ Channel Secret จาก LINE Developers Console ก็เชื่อมได้

### ต้องเสียเงินเพิ่มไหม

LINE Messaging API มีแพ็กเกจฟรีสำหรับเริ่มต้น (1,000 ข้อความ/เดือน) ถ้าส่งมากกว่านั้นต้องซื้อแพ็กเกจเพิ่มจาก LINE

### ใช้ LINE แทน CRM ได้ไหม

ไม่ได้ LINE เป็นช่องทางสื่อสาร ไม่ใช่ระบบจัดการลูกค้า LINE ไม่มี Pipeline, Lead Scoring, Dashboard หรือรายงาน ต้องใช้คู่กับ CRM

### CBoom CRM เชื่อม LINE OA ได้ไหม

ได้ CBoom CRM เชื่อม LINE OA ผ่าน Messaging API พร้อม Auto Lead Creation, Chat History, Send Message from CRM และ Auto Reply ทดลองใช้ฟรี
